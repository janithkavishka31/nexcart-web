# NexCart Web

React + TypeScript storefront for the [NexCart API](https://github.com/janithkavishka31/nexcart-api).

## Development Roadmap
- [x] Project Scaffolding, TypeScript, & Tailwind CSS v4
- [ ] Centralized Redux Toolkit State Store & Axios API Client
- [ ] Authentication, Session Handling & Role Guarding
- [ ] Storefront Catalog, Search & Product Detail Experience
- [ ] Cart Engine, Optimistic Updates & Checkout
- [ ] User Account Dashboard & Order Tracking
- [ ] Seller Portal & Catalog Management
- [ ] Admin Governance & Moderation
- [ ] Docker Containerization & Vercel Deployment
